Primeira versão do **Upphone SIP**, o softphone SIP para Windows da Upp Tecnologia.

## Downloads

| Arquivo | Para quem |
| --- | --- |
| `Upphone-SIP-1.0.0-x64-setup.exe` | **Recomendado.** Instalador para Windows 10/11 de 64 bits |
| `Upphone-SIP-1.0.0-Win32-setup.exe` | Instalador para Windows de 32 bits |
| `Upphone-SIP-1.0.0-x64-portable.zip` | Versão portátil (sem instalar), 64 bits |
| `Upphone-SIP-1.0.0-Win32-portable.zip` | Versão portátil (sem instalar), 32 bits |
| `SHA256SUMS.txt` | Somas SHA-256 para conferir os arquivos |

Na versão portátil, as configurações ficam em `Upphone.ini`, na mesma pasta do `Upphone.exe`. Na versão instalada, ficam em `%APPDATA%\Upphone SIP\`.

## O que tem nesta versão

- Tema claro e escuro que acompanha o Windows, com troca ao vivo e a identidade visual da Upphone
- Interface em português (Brasil)
- Codecs G.711 A-law, G.711 u-law e G.729
- Inicia junto com o Windows
- Sem atualização automática, sem envio de dados de travamento e sem prazo de validade

## Avisos

- **Os arquivos ainda não têm assinatura digital.** O Windows SmartScreen mostra "O Windows protegeu o computador": clique em **Mais informações → Executar assim mesmo**. Em PCs com o **Controle Inteligente de Aplicativos** do Windows 11 ligado, a instalação é bloqueada até a assinatura digital ser adicionada numa próxima versão.
- Sem vídeo, sem Opus e sem TLS/SRTP nesta versão.
