Nova versão do **Upphone SIP**, o softphone SIP para Windows da Upp Tecnologia.

## Downloads

| Arquivo | Para quem |
| --- | --- |
| `Upphone-SIP-1.1.0-x64-setup.exe` | **Recomendado.** Instalador para Windows 10/11 de 64 bits |
| `Upphone-SIP-1.1.0-Win32-setup.exe` | Instalador para Windows de 32 bits |
| `Upphone-SIP-1.1.0-x64-portable.zip` | Versão portátil (sem instalar), 64 bits |
| `Upphone-SIP-1.1.0-Win32-portable.zip` | Versão portátil (sem instalar), 32 bits |
| `SHA256SUMS.txt` | Somas SHA-256 para conferir os arquivos |

Para atualizar, basta instalar por cima da versão anterior (ou trocar o `Upphone.exe` da versão portátil). As configurações e o ramal são mantidos.

## O que mudou

- **Senha do ramal mais protegida.** Agora ela é guardada com a proteção do próprio Windows: só o mesmo usuário, no mesmo computador, consegue lê-la. A senha salva pela versão anterior é convertida sozinha na primeira abertura.
- **Sem chat.** O botão de mensagem saiu do discador (o botão Chamar ocupa a linha toda), assim como a opção "Mensagem" dos menus e dos atalhos.
- **Registros e Contatos:** as colunas acompanham a largura da janela, sem barra de rolagem horizontal. Em janelas estreitas, Duração e Informação ficam ocultas e voltam ao alargar. A seta de ordenação fica ao lado do nome da coluna.
- Corrigido: Registros e Contatos ficavam mais largos que a janela quando o app abria com uma largura salva.
- Telas de chamada no tema claro e escuro: Atender em laranja e Recusar em vermelho.
- Os atalhos do instalador ficam ligados ao app aberto na barra de tarefas, com o ícone correto.

## Avisos

- **Depois de atualizar, não volte para a versão 1.0.0.** Ela não lê a senha no formato novo; se precisar voltar, digite a senha do ramal de novo.
- **A senha não acompanha o arquivo de configurações.** Um `Upphone.ini` (ou uma configuração exportada) levado para outro computador ou outro usuário do Windows chega sem a senha: digite-a de novo no cadastro da conta.
- **Ícone em branco na barra de tarefas?** Se o Upphone foi fixado na barra de tarefas numa versão antiga, desafixe esse atalho e fixe o Upphone de novo.
- **Os arquivos ainda não têm assinatura digital.** O Windows SmartScreen mostra "O Windows protegeu o computador": clique em **Mais informações → Executar assim mesmo**. Em PCs com o **Controle Inteligente de Aplicativos** do Windows 11 ligado, a instalação é bloqueada até a assinatura digital ser adicionada numa próxima versão.
- Sem vídeo, sem Opus e sem TLS/SRTP nesta versão.
