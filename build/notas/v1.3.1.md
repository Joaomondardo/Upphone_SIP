Nova versão do **Upphone SIP**, o softphone SIP para Windows da Upp Tecnologia.

## Downloads

| Arquivo | Para quem |
| --- | --- |
| `Upphone-SIP-1.3.1-x64-setup.exe` | **Recomendado.** Instalador para Windows 10/11 de 64 bits |
| `Upphone-SIP-1.3.1-Win32-setup.exe` | Instalador para Windows de 32 bits |
| `Upphone-SIP-1.3.1-x64-portable.zip` | Versão portátil (sem instalar), 64 bits |
| `Upphone-SIP-1.3.1-Win32-portable.zip` | Versão portátil (sem instalar), 32 bits |
| `SHA256SUMS.txt` | Somas SHA-256 para conferir os arquivos |

Para atualizar, basta instalar por cima da versão anterior (ou trocar o `Upphone.exe` da versão portátil). As configurações e o ramal são mantidos.

## O que mudou

- **Quem está na linha:** durante a ligação, o discador mostra o nome e o número, com barra verde (ativa) ou âmbar (espera).
- Chamada recebida com o número em destaque abaixo do nome.
- Chamadas perdidas em vermelho nos Registros e ícones nos menus de Registros e Contatos.
- Transferir: escolha entre transferência cega e assistida na própria janela.
- O aviso de versão nova passa a ser uma janela do próprio Upphone, que não trava o app durante uma ligação.
- Corrigido: em contatos com mais de um número, o item "Chamar" do menu ficava vazio.

## Detalhes

- A aba ativa fica em laranja, a chamada em espera aparece em âmbar na barra de status e o botão Mudo ligado mostra o microfone riscado em branco.
- A tela da conta ficou com os campos um embaixo do outro.
- A transferência assistida só fica disponível quando o PABX tem o código de transferência assistida configurado no Upphone; sem ele, a opção aparece desabilitada.
- Fechar o aviso de versão nova pelo X conta como "Não": a versão não é oferecida de novo sozinha, mas continua disponível pelo menu "Verificar por atualizações".

## Avisos

- **Os arquivos ainda não têm assinatura digital.** O Windows SmartScreen mostra "O Windows protegeu o computador": clique em **Mais informações → Executar assim mesmo**. Em PCs com o **Controle Inteligente de Aplicativos** do Windows 11 ligado, a instalação é bloqueada até a assinatura digital ser adicionada numa próxima versão.
- Quem está na 1.0.0 ou na 1.1.0 não recebe o aviso de versão nova: precisa instalar esta versão uma vez, manualmente. Vindo da 1.0.0, valem os avisos da 1.1.0: a senha do ramal passa a ser protegida pelo Windows e não acompanha o `Upphone.ini` para outro computador.
- Sem vídeo, sem Opus e sem TLS/SRTP nesta versão.
