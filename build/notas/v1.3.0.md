Nova versão do **Upphone SIP**, o softphone SIP para Windows da Upp Tecnologia.

## Downloads

| Arquivo | Para quem |
| --- | --- |
| `Upphone-SIP-1.3.0-x64-setup.exe` | **Recomendado.** Instalador para Windows 10/11 de 64 bits |
| `Upphone-SIP-1.3.0-Win32-setup.exe` | Instalador para Windows de 32 bits |
| `Upphone-SIP-1.3.0-x64-portable.zip` | Versão portátil (sem instalar), 64 bits |
| `Upphone-SIP-1.3.0-Win32-portable.zip` | Versão portátil (sem instalar), 32 bits |
| `SHA256SUMS.txt` | Somas SHA-256 para conferir os arquivos |

Para atualizar, basta instalar por cima da versão anterior (ou trocar o `Upphone.exe` da versão portátil). As configurações e o ramal são mantidos.

## O que mudou

- **Sons de volta:** a chamada recebida volta a tocar, e também o sinal de chamando, o bipe de uma segunda chamada durante outra e o bipe de fim de chamada (estavam mudos desde a 1.0.0).
- **Ligar ao clicar em links** `tel:`, `sip:` e `callto:` em páginas, e-mails e sistemas.
- Botões Espera, Mudo e Transferir no tema claro/escuro, com destaque quando ligados.
- Teclado da tela Transferir no mesmo estilo do discador.
- Situação da chamada em português ("Chamada em espera", "Chamada ativa").
- Corrigido: com a tela em 150%, o ramal saía cortado na barra de status.

## Ligar ao clicar em links

- O Upphone se registra para os links ao abrir e aparece em **Configurações > Aplicativos > Aplicativos padrão**.
- Se outro programa também atende esses links (por exemplo o Skype for Business), o Windows 11 pergunta qual usar no primeiro clique: escolha o **Upphone SIP** e marque para usar sempre.
- O número é limpo antes de ligar: `tel:+55 (11) 3333-4444` liga para `+551133334444`.

## Sons

- Os sons vêm dentro do `Upphone.exe`. Para usar um som próprio, coloque um `.wav` com o mesmo nome (`ringtone.wav`, `ringing.wav`, `ringing2.wav` ou `hangup.wav`) ao lado do `Upphone.exe`.

## Avisos

- **Os arquivos ainda não têm assinatura digital.** O Windows SmartScreen mostra "O Windows protegeu o computador": clique em **Mais informações → Executar assim mesmo**. Em PCs com o **Controle Inteligente de Aplicativos** do Windows 11 ligado, a instalação é bloqueada até a assinatura digital ser adicionada numa próxima versão.
- Quem está na 1.0.0 ou na 1.1.0 não recebe o aviso de versão nova: precisa instalar esta versão uma vez, manualmente. Vindo da 1.0.0, valem os avisos da 1.1.0: a senha do ramal passa a ser protegida pelo Windows e não acompanha o `Upphone.ini` para outro computador.
- Sem vídeo, sem Opus e sem TLS/SRTP nesta versão.
