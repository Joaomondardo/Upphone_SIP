Nova versão do **Upphone SIP**, o softphone SIP para Windows da Upp Tecnologia.

## Downloads

| Arquivo | Para quem |
| --- | --- |
| `Upphone-SIP-1.2.0-x64-setup.exe` | **Recomendado.** Instalador para Windows 10/11 de 64 bits |
| `Upphone-SIP-1.2.0-Win32-setup.exe` | Instalador para Windows de 32 bits |
| `Upphone-SIP-1.2.0-x64-portable.zip` | Versão portátil (sem instalar), 64 bits |
| `Upphone-SIP-1.2.0-Win32-portable.zip` | Versão portátil (sem instalar), 32 bits |
| `SHA256SUMS.txt` | Somas SHA-256 para conferir os arquivos |

Para atualizar, basta instalar por cima da versão anterior (ou trocar o `Upphone.exe` da versão portátil). As configurações e o ramal são mantidos.

## O que mudou

- **Aviso de versão nova:** uma vez por dia o Upphone confere se saiu uma versão nova e oferece abrir a página de download.
- Novo item no menu: "Verificar por atualizações", para conferir na hora.
- Corrigido: abrir o Upphone de novo enquanto ele salvava as configurações podia mostrar "Failed to open file for writing".

## Como funciona o aviso

- A consulta é feita ao abrir o Upphone e depois de hora em hora, no máximo uma vez por dia, e nunca durante uma chamada.
- **Sim** abre a página desta lista de downloads no navegador. **Não** faz o Upphone não perguntar mais sobre aquela versão, até sair outra (pelo menu ela continua disponível).
- A partir desta versão, as próximas são avisadas sozinhas. Quem está na 1.0.0 ou na 1.1.0 precisa instalar esta versão uma vez, manualmente.

## Avisos

- **Os arquivos ainda não têm assinatura digital.** O Windows SmartScreen mostra "O Windows protegeu o computador": clique em **Mais informações → Executar assim mesmo**. Em PCs com o **Controle Inteligente de Aplicativos** do Windows 11 ligado, a instalação é bloqueada até a assinatura digital ser adicionada numa próxima versão.
- Vindo da 1.0.0, valem os avisos da 1.1.0: a senha do ramal passa a ser protegida pelo Windows e não acompanha o `Upphone.ini` para outro computador, e não dá para voltar à 1.0.0 sem digitar a senha de novo.
- Sem vídeo, sem Opus e sem TLS/SRTP nesta versão.
